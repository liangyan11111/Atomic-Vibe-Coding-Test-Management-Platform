# TestCaseForm 生成规则

## AI 生成时必须遵循

### 表单结构
- 标题字段：必填，1-200 字符，实时校验长度
- 模块选择：下拉单选，必选
- 优先级：P0/P1/P2/P3 四选一，必选
- 用例类型：functional/performance/security/compatibility/usability 五选一
- 前置条件：可选，多行文本
- 测试步骤：至少 1 步，每步包含 action + expected，可拖拽排序
- 预期结果：必填，多行文本
- 标签：可选，支持多标签

### 交互规范
- 步骤拖拽排序使用 DnD Kit
- 添加步骤按钮在步骤列表底部
- 删除步骤需确认（仅 >1 步时）
- 提交按钮在表单底部，提交中显示 loading

### 校验规范
- 实时校验：标题长度、步骤完整性
- 提交校验：全字段校验，错误信息精确到字段
- 校验失败时滚动到第一个错误字段

### 禁止行为
- 禁止在表单内直接调用 API
- 禁止硬编码模块列表
- 禁止自动保存（需用户主动提交）
