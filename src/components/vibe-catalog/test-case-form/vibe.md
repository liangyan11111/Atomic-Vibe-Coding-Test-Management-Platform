# TestCaseForm Vibe 灵魂定义

## 我是什么
测试用例的结构化录入表单，引导测试人员完整、规范地描述一个测试场景。

## 我不是什么
- 不是通用的表单生成器
- 不是用例详情展示页
- 不是批量导入工具

## 适合的场景
- 新建测试用例
- 编辑已有用例
- 用例模板复制

## 不适合的场景
- 批量创建用例（用导入功能）
- 用例评审（用 ReviewPanel）
- 用例执行（用 ExecutionPanel）

## 设计约束
- 视觉：两栏布局（左标题/分类，右步骤/预期），表单项间距 16px
- 交互：步骤可拖拽排序，支持添加/删除步骤
- 数据：标题必填 1-200 字，至少 1 个步骤，优先级必选
- 校验：实时校验 + 提交校验，错误信息精确到字段

## 关联组件
- 依赖：Input (L0), Select (L0), Textarea (L0), Button (L0)
- 被依赖：TestCasesPage (L4)
