# FilterBar 生成规则

## AI 生成时必须遵循

### 布局规范
- 水平排列，筛选项之间 8px 间距
- 每个筛选项宽度自适应，最小 120px，最大 200px
- 右侧放置"重置"按钮（有筛选条件时显示）
- 筛选条件数量 Badge 显示在右侧

### 交互规范
- 选择即生效，无需确认按钮
- 重置按钮清空所有筛选条件
- 单个筛选可通过点击 × 单独清除
- 下拉选项超过 10 个时支持搜索

### 禁止行为
- 禁止筛选条件之间使用 OR 关系（仅支持 AND）
- 禁止在筛选组件内直接调用 API
- 禁止硬编码筛选选项
- 禁止筛选后自动翻页（保持在当前页）
