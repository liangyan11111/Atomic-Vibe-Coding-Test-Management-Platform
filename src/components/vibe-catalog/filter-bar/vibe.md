# FilterBar Vibe 灵魂定义

## 我是什么
数据列表的精准过滤器，让用户从海量数据中快速定位目标子集。

## 我不是什么
- 不是搜索框（用 SearchInput）
- 不是排序控件（集成在 DataTable 表头）
- 不是高级查询构建器

## 适合的场景
- 用例列表的多条件筛选（优先级 + 状态 + 模块）
- 缺陷列表的严重程度/状态筛选
- 测试计划的日期范围/状态筛选
- 任何需要组合多个下拉/日期/枚举条件的列表

## 不适合的场景
- 单条件搜索（用 SearchInput）
- 全文检索（用 SearchInput）
- 数据编辑（用 Form 组件）

## 设计约束
- 视觉：水平排列，筛选项之间 8px 间距，每个筛选项含标签 + 控件
- 交互：选择即生效（无需确认按钮），支持重置全部
- 数据：每个筛选项独立，组合条件为 AND 关系
- 状态：active（有筛选条件）/ inactive（无筛选条件）

- 依赖：Select (L0), Button (L0), Badge (L0)
- 被依赖：TestCasesPage (L4), DefectsPage (L4), TestPlansPage (L4)
