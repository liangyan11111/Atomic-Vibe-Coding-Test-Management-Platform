# DataTable 生成规则

## AI 生成时必须遵循

### 渲染规范
- 表头必须固定在顶部（sticky header）
- 行高固定 48px，不允许动态行高
- 空状态必须使用 Empty 组件展示
- 加载中必须显示 Skeleton 骨架屏

### 交互规范
- 列排序：点击表头切换 asc → desc → none
- 行选择：左侧 Checkbox 列，支持全选/取消全选
- 分页：底部分页器，显示总数和当前页
- 批量操作：选中行后顶部显示操作栏

### 性能规范
- 超过 100 行必须启用虚拟滚动
- 排序和筛选必须 debounce 200ms
- 列宽调整使用 CSS resize，不触发全表重渲染

### 禁止行为
- 禁止在表格内直接调用 API
- 禁止硬编码列定义，必须通过 columns prop 传入
- 禁止使用 index 作为 React key
- 禁止在渲染行中执行复杂计算
