### 8.4 当前代码 UI 问题逐项审查

#### 8.4.1 主题系统严重缺失（🔴 高）

**问题描述**：
- `globals.css` L4 已配置 `@custom-variant dark (&:is(.dark *))`，具备暗色模式基础设施
- `globals.css` 中定义了 `--background`、`--foreground`、`--card` 等 CSS 变量
- **但 `layout.tsx` L23 硬编码 `bg-slate-50`**，完全未使用 CSS 变量
- **无任何主题切换机制**，用户无法切换深色/浅色模式
- 全项目大量组件硬编码颜色值，主题切换成本极高

**硬编码颜色值统计**：

| 文件 | 硬编码颜色 | 应改为 |
|------|-----------|--------|
| `layout.tsx` L23 | `bg-slate-50` | `bg-background` |
| `top-bar.tsx` L26 | `bg-white border-slate-200` | `bg-card border-border` |
| `top-bar.tsx` L36 | `bg-slate-50 border-slate-200` | `bg-muted border-border` |
| `page.tsx` L27 | `border-slate-200 bg-white` | `border-border bg-card` |
| `dashboard-charts.tsx` L29 | `stroke="#F1F5F9"` | 使用主题变量 |
| `dashboard-charts.tsx` L30 | `fill: '#94A3B8'` | 使用主题变量 |

#### 8.4.2 图表配色不支持深色模式（🟠 中）

**问题描述**：
- `dashboard-charts.tsx` 中所有颜色值硬编码为浅色主题下的色值
- 渐变定义使用低透明度（opacity 0.15），在深色背景下几乎不可见
- 网格线使用 `#F1F5F9`（极浅灰），深色背景下不可见
- 坐标轴文字使用 `#94A3B8`（浅灰），深色背景下对比度不足

**影响**：即使实现了深色模式切换，图表也会显示异常。

#### 8.4.3 字体加载不完整（🟡 低）

**问题描述**：
- `globals.css` L46-48 定义了 `--font-sans` 包含 PingFang SC / Hiragino Sans GB
- DESIGN.md 要求数据/代码使用 JetBrains Mono
- **实际未通过 `@font-face` 或 Google Fonts 引入 JetBrains Mono**
- `--font-mono` 仅使用系统 monospace 回退

#### 8.4.4 科技感装饰元素完全缺失（🟡 低）

**问题描述**：
- DESIGN.md 意象锚点为"航天任务控制中心"
- 参考截图包含丰富的装饰元素（网格线、光晕、节点）
- **当前项目无任何装饰元素**，视觉表现力偏弱
- 建议至少为仪表盘页面添加轻量级装饰

#### 8.4.5 DESIGN.md 规范自身问题（🟡 低）

| 问题 | 说明 |
|------|------|
| **规范与实现脱节** | DESIGN.md 写的是浅色 SaaS 风格，但意象锚点是"航天任务控制中心"，两者矛盾 |
| **缺少暗色主题定义** | 规范只定义了一套配色，未考虑深色模式 |
| **缺少图表配色规范** | 未规定图表在深色/浅色模式下的配色方案 |
| **缺少交互细节** | 如 loading 状态、空状态、错误状态的视觉规范 |

### 8.6 UI 最终交付标准

采用**深色科技风**作为整体视觉基调，融合参考截图的现代科技感与测试管理平台的专业性。

#### 8.6.1 主题系统

| 编号 | 标准 | 验收条件 |
|------|------|----------|
| T-1 | 支持 Light/Dark 双主题，TopBar 提供一键切换入口 | 切换后所有页面组件颜色正确响应，无硬编码残留 |

#### 8.6.2 颜色规范

| 编号 | 标准 | 验收条件 |
